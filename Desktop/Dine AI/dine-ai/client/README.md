## ✨ Features

| Feature | Technology |
|---|---|
| 🤖 AI Chatbot | Groq API + LLaMA 3.1 |
| 📸 Food Scanner | Vision AI |
| 💬 Sentiment Analysis | NLP |
| 🥗 Calorie Estimator | Nutrition AI |
| 🧾 PDF Bill Generator | jsPDF |
| 🌙 Dark Mode | CSS + Context API |
| 🔐 Protected Routes | JWT Auth |
| 📋 Order History | MongoDB |

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Context API  
**Backend:** Node.js, Express.js  
**Database:** MongoDB Atlas  
**AI:** Groq API (LLaMA 3.1-8b-instant)  
**Auth:** JWT + bcryptjs  

## 🏃 Run Locally

**Backend:**
```bash
cd server
npm install
node index.js
```

**Frontend:**
```bash
cd client
npm install
npm start
```
